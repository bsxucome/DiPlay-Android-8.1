# DiPlay v0.2.16 安卓 8.1 适配包

安装文件：`DiPlay-0.2.16-Android8.1.apk`。基于上游 v0.2.16 修改，本兼容版最低系统为 Android 8.1（API 27），保留 USB 有线与无线 CarPlay。上游官方包现已支持 Android 7.1+（API 25）；本仓库的适配和验证仍以 Android 8.1 为目标。

本版合入上游针对 Android 8 的 USB 读取与 NCM 分帧修复、无线热点地址恢复、旧系统软件 Opus 麦克风回退，以及设置搜索和视频诊断。实验性音频、视频功能建议在目标车机上逐项测试后再启用。

在车机上打开 APK 安装，或通过电脑执行 `adb install -r DiPlay-0.2.16-Android8.1.apk`。若已安装本仓库发布的 v0.2.13～v0.2.15 安卓 8.1 适配包，可直接覆盖升级并保留应用数据。首次使用按提示授予麦克风等权限；USB 连接还需要同意应用的 VPN 请求。在应用“设置 → 连接”中选择车载热点、Wi‑Fi Direct 或现有 Wi‑Fi；有线连接可从首页进入 USB 连接。应用内更新只查询本仓库发布的同签名兼容包。

此包使用独立签名。若车机已经安装官方签名的 `com.shihab.diplay`，Android 不允许直接覆盖安装；先备份需要保留的设置，再卸载旧包后安装。

验证说明：v0.2.16 签名 APK 已通过 release lint，最低 API 27、版本号 35；在 Android 8.1 模拟器上从本仓库 v0.2.15 覆盖升级成功，应用 UID 和首次安装时间保持不变。首页、USB 准备页、设置和 Wi-Fi Direct 配置页可打开，近期日志未见应用崩溃。Opus、AirPlay 麦克风格式、热点地址恢复及 USB/NCM 分帧策略共 54 项重点测试通过。完整单测因本机缺少 Robolectric 的 Android 镜像且无法联网而中断，需在联网环境补跑；真实 USB／无线 CarPlay 尚未验证。

模拟器无法验证真实车机和 iPhone 之间的 USB／无线投屏、硬件解码、通话音频及方向盘或仪表功能。因此“完美运行”仍需在目标车机上实测；不同车机固件会影响兼容性。如连接失败，请记录车机型号、固件版本、iPhone/iOS 版本，并在应用设置中导出诊断报告。

源码及改动说明见 `DiPlay/` 与 `DiPlay/docs/ANDROID8_COMPAT.md`。上游许可证和第三方声明仍适用。

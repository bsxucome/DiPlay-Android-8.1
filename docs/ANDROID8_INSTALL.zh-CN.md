# DiPlay v0.2.14 安卓 8.1 适配包

安装文件：`DiPlay-0.2.14-Android8.1.apk`。基于上游 v0.2.14 修改，最低系统为 Android 8.1（API 27），保留 USB 有线与无线 CarPlay。Android 8.0（API 26）不在本次适配范围内。

本版包含上游新增的分类设置、默认连接方式、USB／无线恢复与画面调整。实验性的平滑视频、通话回声消除和语音过滤默认关闭，建议在目标车机上逐项测试后再启用。

在车机上打开 APK 安装，或通过电脑执行 `adb install -r DiPlay-0.2.14-Android8.1.apk`。若已安装本仓库发布的 v0.2.13 安卓 8.1 适配包，可直接覆盖升级并保留应用数据。首次使用按提示授予麦克风等权限；USB 连接还需要同意应用的 VPN 请求。在应用“设置 → 连接”中选择车载热点、Wi‑Fi Direct 或现有 Wi‑Fi；有线连接可从首页进入 USB 连接。

此包使用独立签名。若车机已经安装官方签名的 `com.shihab.diplay`，Android 不允许直接覆盖安装；先备份需要保留的设置，再卸载旧包后安装。

验证结果：官方 v0.2.14 包的最低系统为 Android 9（API 28），适配包为 API 27。在 Android 8.1 模拟器中，已从本仓库 v0.2.13 适配包直接覆盖升级，保留了应用安装记录和 Wi‑Fi Direct 选择；新版首页、分类设置、连接设置、无线设置和 USB 准备页均能打开。46 项适配相关测试通过，Release lint 为 0 错误、4 条警告，APK 签名有效。Windows 上的全量单测仍有上一版已知的 6 项环境相关失败（热点存储事务及 Unix `sh` 命令测试）。

模拟器无法验证真实车机和 iPhone 之间的 USB／无线投屏、硬件解码、通话音频及方向盘或仪表功能。因此“完美运行”仍需在目标车机上实测；不同车机固件会影响兼容性。如连接失败，请记录车机型号、固件版本、iPhone/iOS 版本，并在应用设置中导出诊断报告。

源码及改动说明见 `DiPlay/` 与 `DiPlay/docs/ANDROID8_COMPAT.md`。上游许可证和第三方声明仍适用。

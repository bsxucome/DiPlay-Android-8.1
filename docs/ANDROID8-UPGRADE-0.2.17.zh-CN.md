# v0.2.17 安卓 8.1 升级记录

上游标签：`v0.2.17`，提交 `391c90f80b4d54b2732dbbb3e51bf56910768ceb`。兼容分支从已发布的 v0.2.16 升级，工作日期为 2026-10-10。

## 适配范围

- `mobile`、`common`、`shared` 最低系统仍为 API 27；native 的 `APP_PLATFORM` 仍为 `android-27`。
- 版本名为 `0.2.17-android8.1`，版本代码为 36（前版为 35），沿用原包名和签名配置。
- USB 有线、车机热点、Wi-Fi Direct 和现有 Wi-Fi 保留；旧系统的定位检查、BSSID 解析、签名诊断及视频解码回退保留。
- 前台和新增后台更新共用兼容版仓库查询地址，避免提供上游的不同签名 APK。
- Android 8.1/9 诊断导出申请旧版存储权限；拒绝时仍保留可查看和分享的报告。旧系统更新 APK 使用应用专用外部目录，不调用 Android 10 才加入的 MediaStore Downloads API。
- Android 12L 专用的比亚迪通话弹窗控制在 API 27 上隐藏。
- README 默认中文，另提供英文和中文详细说明；上游文档副本已同步。

## 已执行的检查

- 源码公开树检查通过：未将运行时认证资产、签名密钥或安装包加入 Git。
- 合并冲突已处理；版本、最低 API、native 目标平台和更新仓库配置已核对。
- **45 项重点 JVM 测试通过**：麦克风输入策略、16/24/48 kHz Opus 时间戳、RTP 时钟探测、Wi-Fi 扫描暂停和恢复、旧 iPhone iAP2 识别重试与拒绝处理，以及版本比较。

重点测试使用当前 v0.2.17 的相关源码重新编译；未改动的依赖使用已有 v0.2.16 构建输出。该结果不等同于完整 Android 构建、API 27 运行或实际连接验证。

## 待完成

已扩展 API 27 回归用例：USB NCM 损坏块恢复、充电选项保存、Wi-Fi 自动搜索开关、诊断导出、更新 APK 导出、新版提示缓存和隐藏不支持的车辆控制。

仓库要求的完整 CI 命令已尝试，但当前聊天网络受限：Gradle 下载站点无法解析，本机 Gradle 服务也无法连接。网络权限请求未获得额外授权，现有缓存又不含新增的 AndroidX WorkManager 依赖。API 27 Robolectric 测试、完整 CI、release lint、签名 APK 构建和模拟器覆盖升级均**尚未通过**。

恢复构建环境后，需要运行仓库 `AGENTS.md` 规定的单测、lint 和 debug 构建，再使用原签名构建 release APK，核对 API 27、版本代码及签名，并在 API 27 上验证覆盖升级和核心页面。完成前不创建发布标签或宣称已生成可安装的 v0.2.17 包。

USB／无线连接、语音消息、通话、Siri、硬件视频和比亚迪车辆功能仍需实际车机与 iPhone 验证。
